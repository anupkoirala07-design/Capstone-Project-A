# Secure Retail Product Catalogue System
## Project Overview

The Secure Retail Product Catalogue System is a responsive frontend web application developed as part of the Capstone Project during Sprint 3.

The purpose of this project is to demonstrate the development of a modern, user-friendly and responsive retail website using HTML5, CSS3 and Bootstrap while following Agile development practices.

The website allows customers to browse featured electronic products, learn about the project and contact the development team through an online contact form.

---

# Project Objectives

- Develop a responsive multi-page website.
- Apply semantic HTML5.
- Use CSS3 for consistent styling.
- Implement Bootstrap responsive layouts.
- Demonstrate Agile Sprint Development.
- Collaborate using GitHub.
